# Niche Input Template

Короткий шаблон для первого сообщения. Полный обязательный опросник лежит в `docs/NICHE_QUESTIONNAIRE.md`.

Если нужна полноценная оценка `deep_score`, заполняй полный опросник. Этот файл подходит для `quick_scan` или как старт, после которого агент доберет недостающие вопросы.

## Idea Inbox Prompt

Для быстрой выгрузки идеи без оценки:

```text
Зафиксируй идею в inbox без score.

1. Название или рабочее имя:
2. В чем суть:
3. Для кого:
4. Как это может зарабатывать, если уже понятно:
5. Почему я об этом думаю сейчас:
6. Что с ней сделать: просто сохранить / quick_scan / deep_score later / удалить:
```

## Strict Prompt For Deep Score

```text
Оцени нишу по методологии проекта "Анализ Ниш".
Режим: deep_score.

Я заполняю опросник из docs/NICHE_QUESTIONNAIRE.md.
Если блок A неполный, не делай оценку — верни список недостающих обязательных вопросов.
Если блок A полный, но не хватает данных для объективной оценки, сделай только quick_scan с confidence <= 0.55 и напиши, что нужно добрать.

Ответы:

A. Обязательный минимум
1. Название ниши:
2. Конкретная бизнес-модель:
3. Кто платит:
4. Один целевой сегмент:
5. Одна главная проблема:
6. Почему проблема срочная или дорогая:
7. География:
8. Референс номер один:
9. Еще 2-3 конкурента:
10. Наша версия "крепкого номер два":
11. Что клиент получает:
12. Чек:
13. Повторные продажи / LTV:
14. Главный канал первой продажи:
15. Что уже есть у нас:

B-K. Остальные блоки:
Заполню ниже или отмечу "не знаю".
```

## Required For Full Score

Для полноценного `deep_score` нужны:

* заполненный блок A из `docs/NICHE_QUESTIONNAIRE.md`;
* референс или конкурент;
* цены/чеки конкурентов;
* спрос: Wordstat/Trends/SERP/marketplaces/сообщества;
* rough TAM/SAM/SOM;
* юнит-экономика;
* канал продаж;
* срок и стоимость первого теста;
* kill conditions.

## Если данных мало

Агент должен:

* явно написать `confidence <= 0.55`;
* не обновлять хит-парад как окончательный рейтинг;
* дать список 3-5 данных, которые сильнее всего изменят score.

# Project Memory

Эта директория — наследуемая память проекта между чатами, агентами и рабочими сессиями.

Она нужна не для красивой документации, а чтобы новый человек или AI-агент быстро понял:

* зачем были сделаны изменения;
* какие решения уже приняты;
* что проверено;
* какие риски остались;
* какие старые подходы нельзя возвращать без нового теста.

## Как читать в новом чате

1. Прочитать `AGENTS.md`.
2. Прочитать этот файл.
3. Открыть `CURRENT_STATE.md`.
4. Открыть последние 3-5 записей из `worklog/`.
5. Если задача затрагивает методологию, данные, качество анализа или project rules — открыть `DECISIONS.md`.

## Роли файлов

`CURRENT_STATE.md` — быстрый handoff текущего состояния проекта.

`DECISIONS.md` — журнал решений: что теперь считается эталоном, почему, что нельзя откатывать без нового теста.

`worklog/` — рабочая летопись законченных изменений: намерение, контекст, изменения, проверки, результат, риски.

`RETROSPECTIVE_BOOTSTRAP.md` — восстановленная карта прошлого до появления регулярной project memory.

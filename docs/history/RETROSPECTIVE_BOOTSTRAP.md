# Retrospective Bootstrap

Этот файл создан при первом bootstrap проекта 2026-07-01.

## Major Milestones

### 2026-07-01 / Project start

Что происходило:

* Пользователь принес транскрибацию видео Антона Власова о выборе ниш.
* Пользователь сформулировал проблему: много идей, распыление, мало живых денег.
* Запрошен отдельный проект с документацией, памятью, скорингом и живым хит-парадом ниш.

Что было решено:

* Делать docs-first систему, не приложение.
* Разделить быстрые деньги, масштаб и фокус.
* Ввести hard filters и confidence multiplier.
* Вести hit parade в Markdown до появления реальных данных.

Что важно не забыть:

* Цель — не красиво анализировать, а помогать быстрее выбрать, что делать и что закрыть.
* Ниши без конкурентов, рынка, спроса, маржи, LTV или защиты должны получать жесткий штраф.

Связанные решения:

* `DEC-2026-07-01-SCORING-ARCHITECTURE`
* `DEC-2026-07-01-EVIDENCE-FIRST`
* `DEC-2026-07-01-DOCS-FIRST`

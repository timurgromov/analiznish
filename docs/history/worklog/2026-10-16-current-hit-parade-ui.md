# 2026-10-16 — Актуальный хит-парад на сайте

## Ошибка

После добавления «AI для B2B» в реестр и desk-пул сайт показывал его во «Все идеи», но раздел «Сравнение оценённых» читал только frozen-таблицы v0.7 из `data/HIT_PARADE.md`. Поэтому заявленное место 9/21 нельзя было увидеть в хит-параде сайта. Предыдущая проверка публикации охватила карточку, но пропустила эту вкладку.

## Исправление

Первая вкладка сравнения теперь строится из текущего `IDEA_REGISTRY.json`: desk-квалифицированные и выбранные для интервью ставки сортируются той же формулой, что «Все идеи». Строка ведёт в карточку; «Подробнее» показывает причину места и следующий gate. Две frozen-таблицы v0.7 сохранены с явной исторической маркировкой. На мобильном исправлено переполнение страницы таблицей; прокрутка остаётся внутри блока.

## Проверки

`./scripts/check-local.sh`, `node --test` (35 тестов), `node --check dashboard/app.js`, public artifact build и `git diff --check` прошли. В локальном встроенном браузере на 1280×720 и 390×844 видны 21 текущая ставка, «AI для B2B» на месте 9 с рейтингом 56, карточка открывается, исторические вкладки содержат 7 и 9 строк. Ошибок консоли нет; на 390 px ширина страницы равна viewport, таблица прокручивается внутри. Публичную проверку и статус GitHub Pages фиксировать отдельно после публикации.

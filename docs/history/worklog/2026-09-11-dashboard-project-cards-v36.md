# 2026-09-11 — Dashboard v3.6: читаемые карточки объектов

## Изменение

* В `data/IDEA_REGISTRY.json` добавлены обязательные поля `projectSummary`,
  `customer`, `customerOutcome` и `moneyModel` для всех 20 объектов. Формулировки
  взяты из существующих карточек ниш и marketplace batch; они не меняют score,
  evidence, этап или решение.
* В dashboard добавлена одна параметризованная статическая страница
  `project.html?id=<id>`, а не двадцать отдельных вручную собранных страниц.
  Она показывает назначение проекта, клиента, результат, модель денег и текущее
  исследовательское состояние.
* Раскрытая строка реестра получила «Что это за проект» и основную ссылку
  «Открыть карточку проекта». Ссылки, которые раньше неявно открывали JSON или
  Markdown, заменены журналом исследований или явной подписью исходного
  материала.

## Проверки

* `node --check dashboard/app.js`
* `node --check dashboard/project.js`
* `node scripts/validate-idea-registry.mjs`
* Локально открыта `project.html?id=auto-seo-cpa`: отображаются описание,
  клиент, результат, CPA-модель, этап, риск и следующий gate; основной экран
  больше не содержит ссылку на JSON из decision brief.
* Перед публикацией выполнены синтаксические и реестровые проверки. После
  публикации в существующей вкладке владельца Chrome открыт `Авто SEO/CPA`,
  раскрыта строка реестра и выполнен переход по «Открыть карточку проекта».
  Опубликованная карточка показывает клиента, результат и CPA-модель; ошибок
  консоли нет. Отдельный Chrome для проверки не запускался.

## Граница

* Dashboard остаётся read-only. Markdown по-прежнему является подробным
  доказательным материалом, но больше не является основной пользовательской
  страницей объекта.

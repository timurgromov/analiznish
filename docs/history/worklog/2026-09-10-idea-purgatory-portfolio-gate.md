# 2026-09-10 — Чистилище идей и ранний Portfolio Gate

## Intent

Сделать `Анализ Ниш` единым местом для заземления идей и не тратить интервью на
кандидатов, которые ещё не прошли сравнение рынка, ёмкости и экономики.

## Context

Исходная 18-критериальная система Антона Власова сохранилась в scoring v0.7,
а SIGMA добавила последовательность добычи доказательств. Однако в реальном
проходе психологов качественная фильтрация не была оформлена как обязательный
сравнительный score, и run дошёл до подготовки интервью по двум направлениям.

Владелец зафиксировал целевую модель: B2B-подписка `1 000–5 000 ₽/мес`,
`100–1 000` плательщиков, MRR `100 000–5 000 000 ₽/мес` и минимизация
распыления между идеями.

## Changes

* Добавлен `docs/IDEA_PURGATORY_PROTOCOL.md`.
* `data/IDEA_INBOX.md` стал упорядоченным чистилищем с классами `A/B/C/X`.
* Встроен ранний Portfolio Gate: batch 5–10 → `S · SCAN 0–3` → 18 критериев →
  максимум 1–2 финалиста → интервью.
* Синхронизированы agent rules, workflow, SIGMA, scoring, project spec, UX,
  README, input/start prompts и task list.
* Психологический run возвращён с шага 6 на шаг 4. Подготовленные материалы
  интервью сохранены, но рекрутинг запрещён до сравнительного gate A/B/C.

## Verification

  `psychologists-russia-2026-09-09 · S · SCAN · step 4`.

## Result

Сырая идея теперь не теряется и получает понятное место, но не конкурирует с
проверенным рынком. Ресурс на интервью открывается только после раннего
портфельного отбора.

## Risks

Классы `A/B/C/X` остаются приблизительными и зависят от неполного E0-контекста.
Их нельзя читать как рыночный score или прогноз выручки.

# Dashboard v5 — экран решения и одна честная воронка

Дата: 2026-09-13

## Зачем

Сквозная сетка из восьми этапов и 32 счётчиков смешивала разные запуски,
legacy-актив и текущие идеи. Владелец видел много арифметики, но не видел
одного решения, которое действительно требуется сейчас.

## Что изменено

- Первый экран превращён в owner cockpit: общий пул, текущие финалисты, идеи,
  реально дошедшие до интервью, и один следующий gate.
- Главная воронка показывает один выбранный `factory_v2` run. Состав берётся
  только из `idea.runIds`, а результаты checkpoint — только из
  `decisionAudits.checkpointHistory`.
- Batch меньше пяти идей честно помечается как неполный; readiness не выводится
  из score или готовности кода.
- Общая карта восьми стадий оставлена вторичным сворачиваемым обзором и
  показывает только текущее положение идей.
- `active_business` вынесен в отдельный benchmark, чтобы не изображать
  несуществующее последовательное прохождение Factory.
- Сохранены read-only drill-down, фильтры, карточки идей и публичная граница.

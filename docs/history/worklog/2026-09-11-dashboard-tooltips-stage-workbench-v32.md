# 2026-09-11 — Компактные подсказки и идеи внутри этапа, dashboard v3.2

## Intent

Исправить два UX-разрыва после v3.1: определения этапов были показаны
постоянными абзацами и почти вдвое раздули карточки, а нажатие этапа уводило из
воронки в общий реестр. Параллельно объяснить разницу между полным списком,
формальным рейтингом и журналом исследований.

## Owner correction

Владелец прямо запросил маленький `?` с всплывающей подсказкой, а не увеличение
информационной высоты блока. Затем предложил оставлять пользователя на странице
этапов и показывать идеи выбранного этапа прямо под воронкой.

## Changes

* Постоянные описания удалены из восьми карточек этапов и шести карточек
  результатов; высота desktop-карточек снижена с `148px` до `94px` и со
  `116px` до `86px` соответственно.
* У каждого раздела, этапа и результата есть отдельная кнопка `?`. Одно общее
  всплывающее окно открывается по hover, keyboard focus и click/tap; `?` не
  запускает фильтрацию карточки.
* Нажатие этапа больше не переключает вкладку `Все идеи`. Под воронкой
  раскрывается список идей выбранного этапа из `IDEA_REGISTRY.json`.
* Внутри этапа доступны фильтр результата проверки и сортировка по текущему
  рейтингу, предварительной оценке, глубине исследования или названию.
* `Журнал проверок` переименован в `Журнал исследований`: его строки являются
  research-runs. `Хит-парад` переименован в `Сравнение оценённых`: общий
  осторожный рейтинг всех идей остаётся в `Все идеи`, а отдельный раздел
  содержит две формальные несмешиваемые линзы по уже оценённым объектам.

## Evidence limits

После последней правки не запускался отдельный headless-браузер и не создавалась
новая вкладка: это сохраняет заданное владельцем правило браузерной проверки и
не нагружает систему. Фактический live viewport этой проверки — `1232×582`;
мобильная ширина после v3.2 отдельно не эмулировалась. Обработчики hover,
keyboard focus и tap присутствуют в одном tooltip-контроллере; live-проверкой
в этой сессии подтверждён click/tap-сценарий.

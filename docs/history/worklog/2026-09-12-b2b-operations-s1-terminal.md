# 2026-09-12 — Новый B2B operations batch: S0–S1 terminal gate

> **Статус: superseded 2026-09-12.** Этот terminal-вывод ошибочен: наличие
> российских продуктов и услуг подтверждает рынок и денежные workflows. Все
> семь гипотез прошли S1 и припаркованы на S2 до двух независимых свежих problem
> signals. Актуальный source board: `data/discovery/2026-09-12-b2b-operations-s0-context.md`.

## Контекст

После того как legacy-портфель не оставил финалистов, начат новый batch без
опоры на готовый код. Семь направлений пришли из трёх независимых входов:
pain-first, product-first и transaction-first. Они были намеренно записаны как
E0, а не представлены как найденные ниши.

## Что проверено

S0 зафиксировал предполагаемого плательщика, механизм денег, локальное
ограничение и falsifier для каждого кандидата.

На S1 сопоставлены российские продукты и услуги:

* field-service CRM уже покрывают заявки, выезды, акты, счета и оплату;
* B2B order-to-cash уже реализуется как 1С-интегрированный портал;
* сроки договоров, продления и уведомления встроены в локальный 1С-контур;
* аутсорсинговая бухгалтерия продаёт контроль сроков как часть основной услуги;
* для ранней дебиторки и security questionnaire не найден отдельный малый
  российский buyer с безопасным низкоинтеграционным оффером.

## Решение

S0_CONTEXT–S1_MARKET закрыты terminal gate без финалиста. Все семь гипотез
остаются в реестре как quick_scan / failed / E1 с конкретным условием возврата.
Ни интервью, ни traffic, ни action, ни деньги, ни build не открывались.

## Что изменено

* новый source board: data/discovery/2026-09-12-b2b-operations-s0-context.md;
* ACTIVE_RUN и registry зафиксировали complete run;
* factory state и CURRENT_STATE показывают два подряд ранних batch без
  искусственного финалиста;
* IDEA_INBOX сохранил provenance семи сырых направлений.

## Следующий gate

Новый S0 batch начинается только с Jobs, в которых до записи кандидата видны
локальный сегмент и пересечение хотя бы двух независимых входов. Общий workflow
без вертикали больше не является достаточным lead.

Изменения:

* Добавлен `docker-compose.yml` с сервисом `dashboard` на `nginx:1.27-alpine`.
* В `docker-compose.yml` задано явное имя проекта `niche-analysis`, потому что имя из папки с кириллицей и пробелом приводило к `project name must not be empty`.
* Порт закреплен как `127.0.0.1:8765:80`, URL остается `http://127.0.0.1:8765/dashboard/`.
* Проект монтируется в nginx read-only: `./:/usr/share/nginx/html:ro`.
* Включен `restart: unless-stopped`, чтобы контейнер переживал закрытие сессии и перезапуск Docker Desktop.
* README, TASKS и CURRENT_STATE обновлены: runtime больше не описывается как ручной Python server.

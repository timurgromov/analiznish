# Архив референсов

Здесь хранятся подробные исследования конкурентов и внешних проектов, которые нужны как evidence для активной ниши, но не должны дублировать её отдельной строкой в `data/HIT_PARADE.md`.

Файл в этой директории:

- не является активной ставкой или самостоятельным объектом карты;
- может содержать исторические score и строки старых версий hit parade;
- используется только как источник фактов, рисков, механик и сравнений для канонической карточки в `data/niches/`.

На 2026-07-23 исследование «Фотушки» относится к активному проекту «КАДРА».

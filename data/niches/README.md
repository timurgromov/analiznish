# Niche Cards

Здесь хранятся карточки отдельных ниш.

Формат имени:

```text
YYYY-MM-DD-slug.md
```

Шаблон: `docs/NICHE_REPORT_TEMPLATE.md`.

`INDEX.md` — реестр только портфельных карточек v0.7 для портфельного валидатора.
Добавляй в него только объекты, присутствующие в `data/HIT_PARADE.md`. Единый
индекс всех идей для dashboard находится в `data/IDEA_REGISTRY.json`; карточки,
которых нет в hit parade, тоже обязаны иметь там каноническую запись.

Правила:

* одна карточка — одна конкретная ниша и бизнес-модель;
* не смешивать разные сегменты в одной карточке;
* если модель сильно изменилась, лучше создать новую карточку или явно добавить `Rescore History`;
* все важные факты помечать уровнем доказательности.

# Portfolio Closure — фактический итог старого портфеля

Дата: 2026-09-12
Статус: incomplete

## Правило чтения

Этот файл отвечает на один вопрос: можно ли уже искать новые идеи или нужно
сначала закрыть старые объекты через то же сито. Он не является рейтингом и не
разрешает интервью, трафик, продажи, action, деньги или build.

Новая идея не начинает batch, пока в scope остаётся старый asset без
объяснимого исхода Factory v2. Действующий бизнес и market reference не
являются такими asset: они служат соответственно benchmark и картой рынка.

## Единственный незакрытый хвост

Rule24 не должен получать shortcut из-за готового кода. Следующий корректный
run: S0_CONTEXT → S1_MARKET → S2_TREND → S3_LOCALIZE для одного определённого
Job и сегмента. Возможны только два результата:

* failed с внешним фактом и условием возврата;
* finalist, который тогда сравнивается с двумя parked психологическими
  финалистами перед owner choice.

## Что это значит прямо сейчас

* CustDev-ready кандидатов: 0.
* Новые идеи искать: рано.
* Единственная работа до поиска новых идей: закончить Rule24 recovery screen.
* После него: owner выбирает ровно один surviving finalist или фиксирует, что
  портфель не оставил ни одного кандидата. Только во втором случае запускается
  новый discovery batch.

# Interviews

Здесь хранятся только обезличенные итоги реальных CustDev-интервью. Полные
записи, контакты, голос, видео, cookies и персональные данные в Git не попадают;
при необходимости они остаются локально в ignored `.local/`.

Имя файла: `YYYY-MM-DD-niche-participant-id.md`.

Используй `data/interviews/_template.md` и правила из
`docs/CUSTDEV_PROTOCOL.md`.

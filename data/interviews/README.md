# Interviews — только cohort synthesis

В Git разрешены только обезличенные сводки по когорте минимум из пяти
подходящих интервью. Participant-level записи, контакты, даты разговоров,
каналы, raw quotes, аудио, видео и другие данные конкретного человека хранятся
только в ignored `.local/interviews/`.

Публичная сводка не должна позволять восстановить личность участника. В ней
разрешены агрегированные паттерны, частота в когорте, противоречащие случаи,
обобщённые текущие альтернативы, диапазоны затрат и решение gate.

Имя tracked-файла: `YYYY-MM-DD-niche-cohort-synthesis.md`.

Шаблон публичной сводки: `data/interviews/_template.md`. Participant-level
заметки создаются локально без tracked-шаблона и никогда не копируются в
`data/interviews/`.

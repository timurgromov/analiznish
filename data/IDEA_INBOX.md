# Чистилище идей

Сюда попадают сырые идеи до исследования. Цель — убрать идею из головы,
сохранить контекст и сразу поставить её в приблизительную очередь относительно
конечной цели: устойчивая прибыль и возможность проверки без большой
предварительной разработки. Повторяемый cashflow предпочтителен; B2B-подписка
`1 000–5 000 ₽/мес` и `100–1 000` плательщиков — benchmark, но не hard filter.

Это не доказательный рейтинг и не список обязательств. Класс `A/B/C/X`
показывает только соответствие цели по текущим, часто неполным данным. Полные
правила — в `docs/IDEA_PURGATORY_PROTOCOL.md`.

## Классы соответствия цели

| Класс | Значение |
| --- | --- |
| `A` | Сильный кандидат на ближайший batch quick scan. |
| `B` | Потенциал есть, но сначала нужен один ключевой факт. |
| `C` | Парковка: слабое соответствие цели или дорогая проверка. |
| `X` | Hard filter или противоречие текущей цели. |

## Статусы обработки

| Статус | Значение |
| --- | --- |
| `inbox` | Просто зафиксировано, решения пока нет. |
| `quick_scan_candidate` | Достаточно понятно, чтобы быстро отсечь или поставить в очередь. |
| `deep_score_candidate` | Есть шанс на полноценную оценку после заполнения блока A. |
| `parked` | Не трогать сейчас, вернуться только при новых данных. |
| `discarded` | Закрыто, не возвращаться без нового сильного аргумента. |

## Очередь

Идеи сортируются сначала по классу `A → B → C → X`, затем по номеру приоритета
внутри класса. Неизвестное не заменяется оптимистичным баллом.

| Приоритет | Дата | Идея | Тип | Класс | Уверенность | Статус | Почему здесь | Одна следующая проверка | Заметки |
| ---: | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| — | YYYY-MM-DD | Пример | business/content/automation/asset/research/personal tool | B | E0 / низкая | inbox | Есть плательщик, но неясны прибыль и повторяемость | Найти 3 платных референса | Короткий контекст |

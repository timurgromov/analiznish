# Experiments

Здесь хранится журнал проверок оффера, канала, цены, delivery и retention.
Каждый эксперимент должен иметь гипотезу, метрику, success/kill criteria до
старта, фактический результат и решение.

Имя файла: `YYYY-MM-DD-niche-experiment-slug.md`.

Используй `data/experiments/_template.md`. Нельзя менять критерий успеха после
получения результата без отдельной пометки об изменении протокола.
